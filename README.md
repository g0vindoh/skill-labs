# Skill Labs - Node.js Server

A simple HTTP server built with Node.js as part of skill lab exercises.

## 🚀 How to Run

```bash
node server.js
```

Then open your browser and visit: **http://localhost:3000**

## 📌 Available Routes

| Route | Description |
|-------|-------------|
| `/` or `/home` | Welcome message |
| `/greet` | Returns a greeting |
| `/about` | Info about the server |
| anything else | 404 - Not Found |

## 🛠️ Tech Stack

- Node.js
- Built-in `http` module (no external packages needed!)
